## Para rodar

Abra o terminal nesta pasta e execute:

```bash
npm install
npm run dev
```

O Vite inicia o site no computador, normalmente em `http://localhost:5173`.

A busca usa a API Open-Meteo para localizar a cidade e consultar o clima. A página roda localmente, mas precisa de internet para buscar os dados.
